# Яндекс Самокат — API-автотесты

Автотесты REST API учебного сервиса аренды самокатов [Яндекс Самокат](https://qa-scooter.praktikum-services.ru/): курьеры и заказы.

**Стек:** Python · pytest · requests · Allure · Faker

## Что проверяется

8 тестов, создание заказа параметризовано по цвету самоката.

| Эндпоинт | Тестов | Сценарии |
|---|---|---|
| `POST /api/v1/courier` | 3 | успешное создание, повторный логин (409), без обязательных полей (400) |
| `POST /api/v1/courier/login` | 3 | успешный вход, несуществующий курьер (404), пустой логин или пароль (400) |
| `POST /api/v1/orders` | 1 | заказ с цветом BLACK, GREY, обоими цветами и без цвета |
| `GET /api/v1/orders` | 1 | получение списка заказов |

## Как устроен проект

- Созданные в тестах курьеры удаляются после теста фикстурой `delete_courier_after_test`.
- Адреса API собраны в `urls.py`, тестовые данные — в `data.py`, генерация данных — в `helpers.py`.

## Запуск

```bash
pip install -r requirements.txt
pytest tests --alluredir=allure_results
allure serve allure_results
```
